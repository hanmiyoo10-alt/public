# Public Capability Plane

This repository is a **derived public projection** of public-safe artifacts from a private canonical repository.

It is intentionally **not** a release, production, deployment, or runtime authority.

## What is published

Only an explicit allowlist of artifacts that are already publicly distributed is projected here:

- Termux local-stack bootstrap/runtime scripts
- SimCore install/update artifacts
- Local Usage Dashboard plugin/runtime artifacts

The current exact source commits and SHA-256 digests are recorded in `artifacts/provenance.json`.

## What is not published

This repository does not mirror canonical history, private-only source, pull-request diffs, issue data, internal tools, credentials, private device/runtime evidence, or repository administration state.

## Public capabilities

This facade exists so the public-safe surface can use ordinary public GitHub capabilities independently of the private canonical control plane:

- GitHub-hosted Actions
- CodeQL code scanning
- dependency review for public-repository changes
- artifact attestations for the bundled public projection
- GitHub Pages
- public Issues, Discussions, forks and pull requests

Public CI and CodeQL validate only the bytes present in this repository. They are never evidence for private-only canonical code.

## Generated content

`artifacts/**` is generated by the projection workflow and may be overwritten by the next sync. Do not treat a pull request that directly edits generated artifacts as a canonical-source change.

See `CONTRIBUTING.md` for contribution boundaries and `SECURITY.md` for security reporting guidance.
