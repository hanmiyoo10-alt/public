# Contributing

Thanks for helping improve the public surface.

## Good public contributions

Public pull requests are appropriate for documentation, the static Pages site, public validation tooling, and improvements to this facade's non-authoritative presentation.

## Generated artifacts

`artifacts/**` is generated from the private canonical repository through an exact allowlist. Direct edits to generated artifacts are not a path to changing canonical source and may be overwritten automatically.

If an artifact itself needs a source change, open an Issue or Discussion describing the public behavior or artifact that should change. The private canonical repository remains the implementation authority.

## Security boundary

Never submit credentials, tokens, private logs, private repository material, device data, or other sensitive content to this public repository.
