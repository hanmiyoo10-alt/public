# Security Policy

Do not publish sensitive reports, credentials, private repository material, or private runtime/device evidence in a public Issue or Discussion.

For a vulnerability in the public projected artifacts, provide the smallest public-safe reproduction possible. If a report necessarily contains secrets or private canonical information, use GitHub's private vulnerability reporting surface when available instead of a public thread.

This repository is a derived public surface. Security results here apply only to the public bytes present here and do not certify private-only canonical source.
